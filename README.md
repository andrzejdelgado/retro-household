# Retro Household

Routines, rules, Wi-Fi hours and a scheduled TV programme for a household with children under 8, printed for the fridge. A parent-facing web app, mobile first, plus a kid-facing TV app that plays each child's channels like 1990s broadcast television.

- `PLAN.md` — the plan and the decision log
- `DEV-PLAN.md` — build milestones
- `docs/` — goals, personas, insights, journeys, domain model, screen specs, design system, records
- `process/` — the reusable, project-agnostic method
- `best-parctices/` — the practice files the defaults are derived from

## Run

```bash
npm install
npm run dev
```

Parent app at `/`, TV app at `/tv`. Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
