## Steps taken (in order)
1. Derived eight goals from the decision log: unaided setup, informed deviation, fridge-ready print, broadcast TV behaviour, correct and visible screen time, survival across time, clean mobile-first UI, reusable method.
2. Wrote 33 criteria across the goals, each with an ID and a check method (timed run, checklist walk, unit test, print preview, device-mode check, audit, search).
3. Listed ten non-goals from the plan's scope-out section, adding "children over 8" and "English only" which the plan implied but did not list.
4. Wrote a ten-step demo path on one computer and mapped each step to criteria.
5. Checked every decision D01 to D26 against the criteria. All are served or are non-goals.
6. Wrote `process/02-goals.md` (playbook) and this record. Committed and pushed.
